### Pranipremi 🐾
## Purpose

Pranipremi is a pet adoption platform where users can post pets for adoption, request adoptions, and manage adoption requests easily. The project aims to connect animal lovers with pets needing a caring home.

Live URL

🌐 https://your-live-link.vercel.app

## Features
🐶 Add pets for adoption with image, age, category, and location
🔐 Authentication system using Better Auth
📋 Users can send adoption requests for pets
✅ Pet owners can approve or reject adoption requests
🖼️ Responsive and modern UI built with Next.js and Tailwind CSS
📊 Dashboard for managing posted pets and adoption requests
⚡ Dynamic data fetching with MongoDB backend integration
